\# Описание работы скриптов (Лабораторная работа)



Репозиторий содержит три скрипта на Python для работы с базовыми алгоритмами ветвления, циклов и потокового анализа данных.



\## Требования

Для запуска программ необходим установленный интерпретатор \*\*Python 3.x\*\*.



\---



\## 1. Диапазон чисел (`range\_numbers.py`)



\### Как это работает:

Программа запрашивает у пользователя два целых числа (`a` и `b`). На основе их соотношения скрипт автоматически выбирает шаг:

\* Если `a < b`, числа выводятся по возрастанию.

\* Если `a > b`, числа выводятся по убыванию.

\* Если `a == b`, выводится одно число.

Все числа выводятся строго в одну строку через пробел.



\### Запуск:

```bash

python range\_numbers.py

```



\---



\## 2. Статистика потока (`statistics.py`)



\### Как это работает:

Программа анализирует поток чисел "на лету" без сохранения их в память (без использования списков):

1\. Сначала вводится число `n` (количество элементов).

2\. Первое введённое число принимается за стартовую точку для минимума и максимума. Это исключает ошибку некорректной инициализации нулем, если все элементы в потоке отрицательные.

3\. В цикле обрабатываются оставшиеся числа, обновляя текущую сумму, минимум и максимум.

4\. В конце программа выводит минимальное значение, среднее арифметическое и максимальное значение.



\### Запуск:

```bash

python statistics.py

```



\---



\## 3. Повторный ввод (`positive\_input.py`)



\### Как это работает:

Скрипт использует бесконечный цикл `while True` для валидации ввода:

\* Программа требует ввести положительное целое число (строго \\(> 0\\)).

\* Если пользователь вводит `0` или отрицательное число, счетчик отклонённых попыток увеличивается на 1, а цикл запускается заново.

\* Как только введено корректное число, цикл прерывается, программа вычисляет его квадрат и выводит статистику отклонённых попыток.



\### Запуск:

```bash

python positive\_input.py

```
